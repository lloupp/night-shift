# Notas técnicas

- Engine alvo: Godot 4.3+.
- Renderer inicial: Compatibility, para maximizar alcance e facilitar futura avaliação de export Web.
- Resolução interna: 480×270 com upscale para reforçar estética retrô.
- Física: CharacterBody3D e raycast para tiro.
- Câmera: ortográfica, rotacionada em incrementos de 45 graus.
- Assets atuais: primitivas geradas em runtime; arte definitiva ainda não foi iniciada.
