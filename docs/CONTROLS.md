# Controles

| Ação | Controle |
|---|---|
| Mover | WASD |
| Correr | Shift |
| Girar câmera | Q / E |
| Mirar | Botão direito do mouse |
| Atirar | Botão esquerdo do mouse |
| Recarregar | R |
| Interagir | F |

A câmera gira em passos de 45 graus e o movimento do personagem é recalculado em relação à orientação atual da câmera.
